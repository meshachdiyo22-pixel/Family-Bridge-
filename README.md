# Family Bridge - Safe Family Internet Shield

> Yaro yana waya dare da rana? Ba ka san waye yake magana da shi ba?

Family Bridge helps Nigerian parents know if their child is SAFE without reading private chats.

### The Problem
Nigerian youth spend 6+ hours online daily. Parents fear scams, predators, but checking phones breaks trust.

### The Solution - Privacy First!
- **Youth PWA App:** Scans ONLY metadata {time, type, count, action: blocked} — NEVER chats, images, call audio
- **XP Rewards:** +40 XP for 3 hours safe reading, streak bonuses
- **Airtime Wallet:** 100 XP = N100 MTN/Airtel airtime - Parent approves
- **Baba Umar Mentor:** AI Hausa elder with audio coaching "Gaskiya, I blocked one site way fit spoil your phone"
- **Parent Dashboard:** Green SAFE / Yellow Warning / Red Block cards — no private content

### Languages
English, Hausa, Pidgin — with Hausa audio alerts

### Privacy Promise
We see: {time: "10:42pm", type: "adult_site", count: 1, action: "blocked"}
We NEVER see: private chats, images, call audio

### Built With
Llama 3.1 405B (Hausa coaching) + LlamaCoder + React + Tailwind

### How to Run
1. Unzip llamacoder (1).zip
2. npm install
3. npm run dev
